Supabase Database Setup

Kopier og kjør dette SQL-skriptet i Supabase SQL Editor for å opprette redirects-tabellen med riktige tilgangsregler (RLS):

-- 1. Opprett redirects-tabell create table if not exists public.redirects ( id text primary key, google_url text not null, clicks bigint default 0, created_at timestamp with time zone default timezone('utc'::text, now()) not null ); -- 2. Aktiver Row Level Security (RLS) alter table public.redirects enable row level security; -- 3. Tillat offentlig lesing (for omdirigering og admin) create policy "Allow public read" on public.redirects for select using (true); -- 4. Tillat offentlig opprettelse create policy "Allow public insert" on public.redirects for insert with check (true); -- 5. Tillat klikk-oppdatering create policy "Allow public update" on public.redirects for update using (true); -- 6. Tillat sletting create policy "Allow public delete" on public.redirects for delete using (true);
