# NFC & QR Redirect Engine

Privat omdirigeringssystem og administrasjonspanel for NFC-kort og QR-koder.

## Funksjoner
- 🔒 Passordbeskyttet administrasjonsgrensesnitt
- ⚡ Rask og direkte kundeomdirigering for NFC og QR
- 📊 Klikk-teller og sanntidsstatistikk

## Sikkerhet
- Administrasjonspanelet er sikret med privat adgangskontroll.
- Konfigurasjon og nøkler håndteres sikkert via lokale miljøvariabler eller nettleserlagring, og ligger aldri hardkodet i offentlig kode.
